# 我的西班牙文單字本

404 個零基礎（A1）西班牙文單字，分成三條路線：會話與基本表達、生活與旅遊、基礎核心。每天從三條路線各抽 2 個，共 6 個新字。
每個字都有詞性（含陰陽性）、中文、發音、例句與翻譯，並有字卡學習、間隔複習、拼字填空測驗和發音入門頁。

## 使用方式
直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。

## 檔案
- `index.html`：程式本體
- `words.js`：單字資料

## 注意
- 發音使用瀏覽器內建的語音功能（Chrome、Safari、Edge 都支援）。iPhone 請先在「設定 → 輔助使用 → 朗讀內容 → 聲音」下載西班牙文聲音。
- 放在 GitHub Pages 時，學習進度存在手機瀏覽器裡（不會跨裝置同步）。
- 每天學完會顯示一組 4 位數「進度密碼」，換手機或資料不見時可輸入密碼回復進度。
- 「新增」頁的「完整進度備份」可以保存包含複習狀態、收藏、自訂單字的完整進度。
